# LIAM³

A pixel-art boss-rush card game, built as a birthday gift.

Play it live: *[abrown33914.github.io/liam-cubed](https://abrown33914.github.io/liam-cubed/)*

## What it is

A small browser game — three worlds, card-based fights, buffs to earn along the way. Runs entirely in the browser, no install needed.

## Files

```
liam-boss-rush/
├── index.html      ← the whole game
└── art/            ← optional: your own images and music
```

## Hosting it (GitHub Pages)

1. Create a free GitHub account if you don't have one.
2. New repository → public.
3. Upload `index.html` (and an `art` folder if you're using one) via **Add file → Upload files**, then **Commit changes**.
4. Repo **Settings → Pages** → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.
5. Wait a minute, refresh that page, and you'll get a live link like `https://yourusername.github.io/liam-boss-rush/`.
6. Turn that link into a QR code with any free generator.

Re-uploading `index.html` later updates the live game automatically — same QR code, latest version.

## Customizing it

Everything is editable directly in the file — text, colors, images, music.
